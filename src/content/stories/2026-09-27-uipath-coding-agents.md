UiPath's coding-agent integration is now generally available across agents, Maestro flows, coded apps, API workflows, human-in-the-loop tasks, and other automation artifacts.

## Why it matters

Enterprise automation is becoming **agent-authorable infrastructure**. The important part is not the code generation itself, but preserving governance, deployment, and evaluation through the platform's existing lifecycle.
