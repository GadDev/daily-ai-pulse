# Support

The Daily AI Pulse is an independently maintained open-source publication project.

## Documentation

Start with the project documentation in [`docs/`](./docs/):

- [`ARCHITECTURE.md`](./docs/ARCHITECTURE.md) — technical structure and deployment model
- [`PRODUCT.md`](./docs/PRODUCT.md) and [`PRD.md`](./docs/PRD.md) — product direction
- [`CONTENT_MODEL.md`](./docs/CONTENT_MODEL.md) — story and daily-edition schemas
- [`EDITORIAL.md`](./docs/EDITORIAL.md) — evidence and editorial standards
- [`DESIGN_SYSTEM.md`](./docs/DESIGN_SYSTEM.md) — visual language
- [`DAILY_ISSUE.md`](./docs/DAILY_ISSUE.md) — daily publishing workflow

## Bugs and feature requests

Use GitHub issues and the provided templates. Include enough context for another person to reproduce the problem or understand the proposed outcome.

There is no guaranteed response-time or support SLA.

## Security

Security vulnerabilities should **not** be filed as public support requests. Follow [`SECURITY.md`](./SECURITY.md).

## Conduct

For community or contributor-conduct concerns, follow [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).
