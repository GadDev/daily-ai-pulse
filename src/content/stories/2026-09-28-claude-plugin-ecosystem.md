Anthropic opened a developer submission portal for Claude plugins and a marketplace that combines connectors, plugins, agents, products, and service partners.

Plugins can package remote MCP connectors, Agent Skills, or both, and move through a review process before directory publication.

## Why it matters

Agent extensions are becoming an **application distribution surface**. Review, provenance, update integrity, permissions, and analytics now matter as much as tool ergonomics.
