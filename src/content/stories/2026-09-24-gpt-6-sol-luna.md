OpenAI released GPT‑6 Sol and GPT‑6 Luna in the API, Codex, and ChatGPT, positioning them as different capability/cost points below Astra.

The API changelog lists Sol at $2 input / $0.20 cached input / $10 output per million tokens for the standard tier, and Luna at $0.10 / $0.01 / $0.50.

## Why it matters

Model choice is becoming an architectural routing decision. The cost spread is large enough that teams should evaluate **which tasks genuinely need Sol-class reasoning and which can move to Luna**.
