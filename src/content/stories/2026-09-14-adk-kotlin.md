Google's Agent Development Kit for Kotlin reached 1.0 with parity across the core ADK surface and additional Android-first features.

The release includes local model support through LiteRT-LM, cloud reasoning through Firebase AI, process-persistent state, semantic memory, context compaction, and type-safe function calling.

## Why it matters

Agent frameworks are moving beyond Python-first prototypes. Kotlin support makes agent patterns more credible for Android, JVM services, and mixed local/cloud workflows.
